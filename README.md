### Trading Company System

**A Python-based marketplace and trading management application.**

🔗 **Repository:** [Trading-Company-System](https://github.com/Arman00GH/Trading-Company-System)

This project is part of my effort to move beyond isolated programming exercises and build a more complete application with multiple interacting components.

The system models a trading company and includes functionality related to users, products, contracts, and financial records.

#### Key Features and Technical Areas

* **User Management:** Organizing user accounts and role-based functionality.
* **Role-Based Access:** Structuring different responsibilities for users, administrators, accountants, and the CEO.
* **Product Management:** Managing product information and product-related operations.
* **Contract Management:** Representing trading contracts and their statuses.
* **Database Integration:** Connecting application logic to MySQL for structured data storage.
* **Data Persistence:** Working with JSON and database-backed storage.
* **Application Logic:** Implementing business rules, validations, and interactions between system components.
* **Code Organization:** Applying object-oriented programming to organize related data and behavior.

#### What I'm Learning Through This Project

Building this application has given me practical opportunities to investigate how different parts of a software system fit together.

I'm using the project to improve my understanding of database integration, object-oriented design, error handling, application state, and the challenges of maintaining consistency across related records.

The project is also an ongoing learning exercise: I aim to improve its architecture, security, testing, and maintainability as my skills develop.
